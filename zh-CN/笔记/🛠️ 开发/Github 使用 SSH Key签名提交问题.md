# Github 使用 SSH Key签名提交问题

最近在进行 Github 提交的时候，其实一直在想为什么自从把 GPG 签名改成 SSH Key 签名后，提交就全部变成神秘的未验证了。

## 问题原理

实际上单纯是因为 Github 的机制导致了误解。

如图所示，可以看见实际上 SSH Key 区分为**认证**和**签名**两种，之前一直都没发现这个区别，导致没有配置**签名SSH Key**才导致未验证的问题，补上即可。
