# Linux系统各目录的用处

首先，Linux的一大设计理念是**一切皆文件**。`/`就是所有文件的根，也称之为**根目录**。

- `/bin` - 用户基础命令，包括但不限于`ls`,`cd`,`cp`,`mkdir`等命令。
- `/sbin` - 管理员命令，权限管理等需要管理权限的命令。
- `/boot` - 引导分区，存放的是内核文件和引导程序。
- `/dev` - 设备文件，把所有外设或内部硬件都变成了文件存放调用。
- `/etc` - 系统配置，存放了几乎90%的配置，例如环境变量、网络、服务配置等。
- `/proc` - 虚拟目录，不占用实际空间，存放运行时数据。
- `/home` - 用户目录，存放每个用户的个人数据。
- `/tmp` - 缓存目录，重启就清空。
- `/root` - 管理员的用户目录。
- `/run` - 系统运行时产生的临时文件，关机清空。
- `/usr` - 系统软件安装目录。
- `/var` - 软件数据目录，包括运行日志、数据库数据等内容。
- `/lib` - 依赖库文件目录。
- `/mnt` - 挂载目录（手动），通常空间挂载后会放在这下面。
- `/media` - 挂载目录（自动），通常移动设备插入后会自动挂载在这。
- `/opt` - 其他软件安装目录，自己下的软件基本上在这。
